# Barza Quotation Builder

Editable quotation template for BARZA TRADING CO. Open `index.html` locally or use the [published site](https://mir4zzz.github.io/barza-quotation-builder/).

Edit the quotation details and item rows, then choose **Print / Save PDF** for an A4 quotation. Totals, savings, discount, and amount in words update automatically. Drafts are saved in your browser's local storage on the device you use; they are not synced between devices.

The repository and Pages site are public. The template includes BARZA TRADING CO. contact details, GSTIN, and example prices.
